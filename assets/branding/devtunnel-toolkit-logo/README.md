# DevTunnel Toolkit - identidade visual

Arquivos vetoriais de produção do DevTunnel Toolkit.

- `logo.svg`, `logo-dark.svg` e `logo-contrast.svg`: assinaturas horizontais.
- `logo-icon.svg`, `logo-icon-dark.svg` e `logo-icon-contrast.svg`: símbolos transparentes.
- `logo-icon-background.svg`, `logo-icon-dark-background.svg` e `logo-icon-contrast-background.svg`: símbolos com fundo.
- Os PNGs são derivados dos SVGs correspondentes e existem para compatibilidade.

Paleta principal: `#1473E6`, `#20C7D4` e `#102B32`. A variação escura usa
`#42D3BA`, `#4CC9F0` e `#E8F2F4`.

O símbolo combina portal de túnel, duas setas de fluxo e uma engrenagem com
chave. Os SVGs são autocontidos, sem fontes, scripts ou recursos externos.
